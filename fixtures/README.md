# Тестовый экипаж локальной станции

`crew-monitor-npcs.yml` — серверные прототипы для ручного тестирования консоли.
Они не входят в клиентский установщик. Шесть мирных людей с HTN-прогулками,
ID-картами и униформой в режиме `SensorCords`: имя, профессия, здоровье, координаты.
Поведение `IdleCompound` выбирает доступные точки пола поблизости и чередует движение
с короткими остановками. Специальные `PathfindPoint`-маркеры на карте не требуются.

Для локального тестового сервера с админскими правами:

1. В игровой консоли выполнить `loadprototype` и выбрать `crew-monitor-npcs.yml`.
2. Встать на станции рядом с рабочей консолью мониторинга и сервером датчиков.
3. Выполнить команды из `crew-monitor-spawn.txt` по одной либо скопировать файл
   в клиентский UserData и выполнить `exec crew-monitor-spawn.txt`.
   На этом компьютере UserData — `%APPDATA%/Space Station 14/data`.
4. Открыть консоль экипажа и дождаться обновления датчиков.

Каждый запуск spawn-файла создаёт ещё шесть NPC. Сохранение существующих NPC между
раундами/перезапусками не настроено; после перезапуска потребуется снова загрузить
прототипы и выполнить spawn. Мод клиента не создаёт этих NPC самостоятельно.
