# Зов о помощи / Distress Call

Display names changed in ModLauncher 0.1.7; the ID `death-rattle`, DLL and mod version are unchanged. Previously listed as Предсмертный хрип / Death Rattle.

Версия мода **0.1.2**, ID `death-rattle`, DLL `DeathRattle.Mod.dll`.
Для нового пункта каталога нужен ModLauncher **0.1.6**. Включите мод в библиотеке,
примените выбранный профиль и перезапустите игровой клиент. По умолчанию мод отключён.

## Поведение

Когда здоровье вашего управляемого персонажа становится «ужасным» — штатный alert
`HumanHealth`, severity **4** — мод отправляет через обычный канал рации:

> Помогите, я умираю!

При английском интерфейсе лаунчера: `Help, I'm dying!`.

Одна попытка на эпизод; постоянное ужасное здоровье не вызывает повторные сообщения.
Улучшение здоровья разрешает новую попытку, но между попытками проходит минимум
**30 секунд**, даже при смене тела. Если новый эпизод начался во время этой паузы,
мод дождётся её окончания, пока здоровье остаётся ужасным. Проверка выполняется
по обновлениям штатных alerts и раз в 250 мс. Выход из персонажа очищает эпизод.
Критическое состояние, смерть, призрак и `BorgHealth` сами по себе не вызывают сообщение.

Используется `IChatManager.SendMessage(";…", ChatSelectChannel.Radio)` — тот же
путь и префикс, что у штатного радио-чата. Сервер проверяет возможность говорить,
наличие и работу рации, ограничения речи и частоту сообщений. Мод не подтверждает
доставку, не обходит эти проверки и не меняет введённый пользователем текст чата.
Язык реплик следует языку интерфейса лаунчера: русский при `ru`, английский при `en`.
Bootstrap передаёт сохранённый язык профиля через `SS14_MOD_LANGUAGE`.
После смены языка примените профиль и перезапустите игровой клиент.

## Кто нападает

Если клиент получил положительный урон с явным `Origin` для вашего персонажа
не более **5 секунд** назад, вместо базового призыва отправляется одно предложение:

- Для персонажа: `Помогите, меня убивает Анна Смирнова!`
- Для существа: `Помогите, меня убивает паук!`

При английском интерфейсе: `Help, Alex Smith is killing me!` или
`Help, spider is killing me!`. Игровое имя сохраняется как получено от игры;
мод переводит текст реплики, а не имена персонажей.

В реплике нет двоеточия и слова «сущность». Если имя неизвестно, сохраняется базовый призыв.

Имя берётся через штатный `Identity.Name` с вашим персонажем как наблюдателем;
маскировка и неизвестное имя сохраняются. Наличие `HumanoidProfileComponent`
или прежнего `HumanoidAppearanceComponent` определяет гуманоидного персонажа,
включая NPC; наличие игрока за ним не определяется. Самоповреждение, лечение,
чужой урон, повтор предсказания и устаревшие источники не дают обвинения.
Новый урон с неизвестным источником сбрасывает прежнего нападающего.

**Ограничение:** обычный серверный `DamageableComponentState` не содержит `Origin`.
В проверенной сборке `DamageableHandleState` вызывает `OnEntityDamageChanged` без
него. Поэтому для многих серверных атак будет отправлен только базовый призыв;
клиентский мод не может гарантированно назвать стрелка или нападающего.
Соседние сущности и анимации замахов не используются для догадок.
Гарантированное определение всех атак потребует отдельной поддержки на сервере.

## Проверки и совместимость

`DeathRattle.Tests` проверяет политику и реальные Harmony hooks на минимальных
контрактах: русский/английский язык реплик, радио-префикс, человек/сущность, лечение, чужой и неизвестный источник,
повтор предсказания, polling, несовместимый content и изоляцию ошибок.

```powershell
dotnet run --project DeathRattle.Tests/DeathRattle.Tests.csproj -c Release
./scripts/Test-DeathRattleApi.ps1 -GameDirectory <game-assemblies-directory>
```

Контракты проверены по локальным DLL **Robust 275.0.0**. Живая проверка отправки
и доставки по рации ещё требуется; совместимость со всеми форками не заявляется.
Отсутствие обязательных API отключает мод с записью в `mods.log`; сбой необязательного
определения нападающего сохраняет базовый призыв, а сбой отправки отключает автоматику.

## English

Enable **Death Rattle** in ModLauncher 0.1.6 and restart the client. At native
`HumanHealth` severity 4 it attempts a radio distress call in the launcher's interface language once per episode,
with a 30-second minimum interval. A recent explicit damage origin can add the
visible attacker name in a single sentence without a colon or an entity label. Standard replicated
damage omits this origin, so many attacks have no attribution. Server speech and
radio checks still apply. English replies are `Help, I'm dying!` and
`Help, Alex Smith is killing me!`; visible names are preserved. Restart the game
after changing the launcher language. Live radio delivery remains unverified.
