# Переговоры / Conversations

Отдельный мод **0.1.1** для штатного чата SS14. Входит в ModLauncher **0.1.5**. Основа — разбор имён и каналов из
`ss14-crew-monitor/src/CrewMonitor/Conversations.cs`. Внешнее приложение и HTTP не нужны.

## Использование

1. В библиотеке ModLauncher включите **Переговоры**, примените набор модов и запустите игру.
2. Перед сообщениями отображается время `чч:мм:сс`. Кнопка **Время** отключает его.
3. **Переговоры** раскрывает панель над историей чата.
4. Введите часть имени: поиск без учёта регистра оставляет сообщения этого говорящего.
   В отдельном поле **Поиск по сообщениям** введите слово или фразу, например `зомби`:
   останутся сообщения с `зомби!`, `ЗОМБИ` и другими вхождениями этой строки. Исходные
   имена и время сохраняются; поиск работает только по тексту, без учёта регистра.
5. Нажмите одно или несколько имён в списке. **Только выбранные** отключает отбор,
   сохраняя выбор; выбор первого имени включает отбор автоматически.
6. Выберите отдел / канал рации. Варианты появляются из полученных сообщений,
   включая каналы серверных форков.
7. **Сбросить** очищает поиск, отдел и выбор людей. Штатные фильтры каналов управляются
   обычными кнопками. Сворачивание панели сохраняет отбор; его статус виден сверху.

Используются штатные Robust Button, LineEdit, OptionButton, ScrollContainer,
стиль `ChatFilterOptionButton` и существующий OutputPanel. Цвета сообщений, разметка,
ссылки, ввод и канал отправки остаются игровыми. Есть RU/EN; разные окна чата имеют
независимые фильтры. Список показывает первые 100 совпадений имён, остальные доступны
через уточнение поиска. Отбор применяется ко всей штатной истории.

## Значение данных и ограничения

- Время — **получение клиентом по игровым часам**, вычисленное из сохранённого тика
  истории и `IGameTiming.TimeBase / TickPeriod`. Это не часы компьютера и не время
  от начала раунда. ChatMessage не содержит точную дату произнесения на сервере.
  Неизвестное время — `—`; повторное отображение не меняет отметку.
- Отдел означает **канал рации**, например «Безопасность» или «Инженерный».
  Принадлежность человека к отделу из этого не выводится. Отбор не включает его
  общую рацию или локальный чат только потому, что он говорил в канале отдела.
- Говорящий определяется отображаемым именем голоса без префикса должности.
  Одинаковые имена объединяются; смена голоса или имени даёт другого собеседника.
  Неизвестные отправители и системные сообщения видны без дополнительных фильтров.
- Поиск имени, поиск текста, выбранные люди и отдел объединяются через AND; выбранные имена — OR.
  Штатные Radio/OOC/LOOC и другие фильтры продолжают действовать.

Используется только полученная `ChatUIController.History`: без новых подписок,
сетевых запросов и записи чата на диск. Второй истории нет; метаданные удерживаются
слабыми ссылками. Срок жизни истории определяется штатным клиентом.

## Проверки

```powershell
dotnet run --project Conversations.Tests/Conversations.Tests.csproj -c Release
```

56 проверок: разметка имён и рации, OOC/LOOC/Dead, каналы форков, поиск слов и фраз в старых и новых сообщениях, несколько людей, сочетание фильтров,
неизвестные данные, исторические тики и переполнение часов. Реальные Harmony hooks
устанавливаются на тестовый контракт UI: события кнопок, повторное отображение,
штатный фильтр каналов, независимые окна и очистка после исключения.
Тестовая сборка `Robust.Client` — заглушка API; она не входит в payload.

Точки подключения: конструктор `ChatBox`, `OnMessageAdded`, `AddLine`, поля
`_controller / _timing` и штатная `Repopulate`. API сверяется с локальными DLL
Robust 275.0.0 / Content.Client. Адаптер зависит от версии игры.
Локальная проверка подтвердила панель, время, поиск текста и сброс. Ещё требуется проверить: UI scale,
радиоканалы сервера, прокрутка, переподключение и звуки уведомлений.

Новый ID требует лаунчер 0.1.5 с новым встроенным каталогом; опубликованный 0.1.4
его не знает. Crew Console, Hello World и bootstrap сохраняют версии 0.1.2.
